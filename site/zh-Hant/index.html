特色一覽
本專版特色

本專版特色

  • 全螢幕沉浸式 CarPlay：適配並隱藏左側系統導覽列。
  • 全域懸浮小白點：CarPlay 中也保持顯示，點一下返回 DiPlay 主頁；主頁點一下返回上一屏，長按回到 CarPlay。
  • CarPlay 內車機應用：可開啟原生應用，長按進入解除安裝。
  • 應用列表編輯：勾選顯示、拖曳排序；支援全選 / 系統 / 非系統。
  • Wi-Fi Direct 預設直連；混合藍牙探索；可填車機藍牙位址。
  • 預設 30 fps（面向 i.MX6）；方向盤媒體鍵與可選 Siri 鍵。
  • Root 強制全域隱藏系統導覽列（需 su）。
  • 安卓終端（實驗性）：關於頁連點版本號開啟；請謹慎使用。
安裝到車機

安裝到車機

  1. 停車後從 GitHub Releases 下載 APK（USB 或 adb）。
  2. 解除安裝其他簽章的 DiPlay 後，用車機檔案管理員安裝本包。
  3. 開啟 DiPlay；iPhone 加入車機熱點並保持藍牙開啟。
  4. 點「連接手機」，在 iPhone 上允許 CarPlay。

日常使用不需要 ADB。預設 Wi‑Fi Direct 直連；可選車機熱點（SoftAP）。

版本歷史

v1.0.0

  • CarPlay 认证：内置 MFi 认证密钥，恢复无线 CarPlay 连接。
  • 连接：Wi‑Fi Direct 默认直连，可选车机热点（SoftAP）；混合蓝牙发现。
  • 显示 / 车辆：全屏沉浸、默认 30 fps、CarPlay 内车机应用、悬浮小白点、默认上报 GPS。
  • 方控 / Siri：方向盘媒体键直连 CarPlay HID（切歌 / 音量）；可选 Siri 键，支持窗口按键学习与 root(su) 自动启用无障碍（兼容 API 19，免 adb 弹窗）。
  • Root：全局隐藏系统导航栏（需 root / su）。
  • 终端（实验性）：关于页连点版本号打开；修复精简 ROM 缺 PATH/HOME 导致的启动崩溃，错误提示显示异常位置。
  • 系统设置：拨号 #518200# 打开原生系统设置入口。
  • 工程：com.shihab.diplay，versionCode 100；模块 mobile / common / shared；minSdk / targetSdk 19。
