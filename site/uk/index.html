Звичний інтерфейс
Фокус CS75 Plus

Фокус CS75 Plus

  • Імерсивний CarPlay: приховати ліву системну панель.
  • Плаваюча кулька видна і в CarPlay: торкання — у DiPlay, на головній — Назад, утримання — у CarPlay.
  • Програми ГУ в CarPlay; довге натискання — видалення.
  • Редактор списку: позначки та перетягування.
  • Wi-Fi Direct за замовчуванням; точка доступу (SoftAP); гібридний Bluetooth.
  • 30 fps за замовчуванням; кнопки керма та опційний Siri.
  • Root: примусово сховати системну панель навігації глобально (потрібен su).
  • Android-термінал (експериментально): оболонка на пристрої; використовуйте обережно.
Встановлення в автомобілі

Встановлення в автомобілі

  1. На стоянці завантажте APK з GitHub Releases на USB.
  2. Видаліть інший DiPlay і встановіть цей APK.
  3. Відкрийте DiPlay, підключіться до точки доступу авто або USB і натисніть «Підключити телефон».
  4. Підтвердьте запити довіри на iPhone.

ADB для щоденного використання не потрібен. Wi-Fi Direct за замовчуванням; точка доступу авто (SoftAP) опційно.

Історія версій

v1.0.0

  • CarPlay 认证：内置 MFi 认证密钥，恢复无线 CarPlay 连接。
  • 连接：Wi‑Fi Direct 默认直连，可选车机热点（SoftAP）；混合蓝牙发现。
  • 显示 / 车辆：全屏沉浸、默认 30 fps、CarPlay 内车机应用、悬浮小白点、默认上报 GPS。
  • 方控 / Siri：方向盘媒体键直连 CarPlay HID（切歌 / 音量）；可选 Siri 键，支持窗口按键学习与 root(su) 自动启用无障碍（兼容 API 19，免 adb 弹窗）。
  • Root：全局隐藏系统导航栏（需 root / su）。
  • 终端（实验性）：关于页连点版本号打开；修复精简 ROM 缺 PATH/HOME 导致的启动崩溃，错误提示显示异常位置。
  • 系统设置：拨号 #518200# 打开原生系统设置入口。
  • 工程：com.shihab.diplay，versionCode 100；模块 mobile / common / shared；minSdk / targetSdk 19。
