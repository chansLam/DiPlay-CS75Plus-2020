Una experiencia familiar
Enfoque CS75 Plus

Enfoque CS75 Plus

  • CarPlay inmersivo: oculta la barra de navegación izquierda.
  • La bola flotante también se ve en CarPlay: toque = volver a DiPlay, en la home toque = Atrás, mantener = volver a CarPlay.
  • Apps del coche en CarPlay; mantener pulsado para desinstalar.
  • Editor de lista: marcar y arrastrar para ordenar.
  • Enlace Wi-Fi Direct por defecto; hotspot (SoftAP); Bluetooth híbrido.
  • 30 fps por defecto; teclas del volante y Siri opcional.
  • Root: ocultar globalmente la barra de navegación del sistema (requiere su).
  • Terminal Android (experimental): shell en el dispositivo; úsala con cuidado.
Instalar en el coche

Instalar en el coche

  1. Con el coche aparcado, descarga el APK desde GitHub Releases.
  2. Desinstala cualquier otro DiPlay e instala este APK.
  3. Abre DiPlay; el iPhone se une al hotspot del coche con Bluetooth activo.
  4. Pulsa Conectar teléfono y permite CarPlay en el iPhone.

ADB es opcional. Wi-Fi Direct por defecto; hotspot del coche (SoftAP) también disponible.

Historial de versiones

v1.0.0

  • CarPlay 认证：内置 MFi 认证密钥，恢复无线 CarPlay 连接。
  • 连接：Wi‑Fi Direct 默认直连，可选车机热点（SoftAP）；混合蓝牙发现。
  • 显示 / 车辆：全屏沉浸、默认 30 fps、CarPlay 内车机应用、悬浮小白点、默认上报 GPS。
  • 方控 / Siri：方向盘媒体键直连 CarPlay HID（切歌 / 音量）；可选 Siri 键，支持窗口按键学习与 root(su) 自动启用无障碍（兼容 API 19，免 adb 弹窗）。
  • Root：全局隐藏系统导航栏（需 root / su）。
  • 终端（实验性）：关于页连点版本号打开；修复精简 ROM 缺 PATH/HOME 导致的启动崩溃，错误提示显示异常位置。
  • 系统设置：拨号 #518200# 打开原生系统设置入口。
  • 工程：com.shihab.diplay，versionCode 100；模块 mobile / common / shared；minSdk / targetSdk 19。
