Highlights
What makes this build special

What makes this build special

  • Immersive CarPlay: hide the left system navigation bar for a full-width display.
  • Floating ball shows in CarPlay too; tap returns to DiPlay, on the home tap = Back, long-press = return to CarPlay.
  • Head-unit apps inside CarPlay: launch native apps; long-press to uninstall.
  • App list editor: check which apps show, drag to reorder (system / non-system filters).
  • Wi-Fi Direct-first wireless link; hybrid Bluetooth discovery; optional car BT MAC in settings.
  • Default 30 fps for i.MX6-class VPUs; steering-wheel media keys and optional Siri.
  • Root: force-hide the system navigation bar globally (requires su).
  • Android terminal (experimental): on-device shell via About → tap version; use with care.
Install on the car

Install on the car

  1. While parked, download the APK from GitHub Releases (USB stick or adb).
  2. Uninstall any other DiPlay build, then install with the head-unit file manager.
  3. Open DiPlay; join the car hotspot on the iPhone with Bluetooth on.
  4. Tap Connect phone and allow CarPlay on the iPhone.

ADB is optional. Wi‑Fi Direct by default; car hotspot (SoftAP) also available.

Updates & signing

Signed with v1+v2 for Android 4.4. Same-key updates can overwrite this package; different keys cannot. In-app update checks GitHub Releases.
