特色一览
本专版特色

本专版特色

  • 全屏沉浸式 CarPlay：适配并隐藏左侧系统导航栏。
  • 全局悬浮小白点：CarPlay 中也保持显示，点击返回 DiPlay 主页；主页点击返回上一屏，长按回到 CarPlay。
  • CarPlay 内车机应用：可打开原生应用，长按进入卸载。
  • 应用列表编辑：勾选显示、拖动排序；支持全选 / 系统 / 非系统。
  • Wi-Fi Direct 默认直连；混合蓝牙发现；可填车机蓝牙地址。
  • 默认 30 fps（面向 i.MX6）；方控媒体键与可选 Siri 键。
  • Root 强制全局隐藏系统导航栏（需 su）。
  • 安卓终端（实验性）：关于页连点版本号打开；请谨慎使用。
安装到车机

安装到车机

  1. 停车后从 GitHub Releases 下载 APK（U 盘或 adb）。
  2. 卸载其他签名的 DiPlay 后，用车机文件管理器安装本包。
  3. 打开 DiPlay；iPhone 加入车机热点并保持蓝牙开启。
  4. 点「连接手机」，在 iPhone 上允许 CarPlay。

日常使用无需 ADB。默认 Wi‑Fi Direct 直连；可选车机热点（SoftAP）。

版本历史

v1.0.0

  • CarPlay 认证：内置 MFi 认证密钥，恢复无线 CarPlay 连接。
  • 连接：Wi‑Fi Direct 默认直连，可选车机热点（SoftAP）；混合蓝牙发现。
  • 显示 / 车辆：全屏沉浸、默认 30 fps、CarPlay 内车机应用、悬浮小白点、默认上报 GPS。
  • 方控 / Siri：方向盘媒体键直连 CarPlay HID（切歌 / 音量）；可选 Siri 键，支持窗口按键学习与 root(su) 自动启用无障碍（兼容 API 19，免 adb 弹窗）。
  • Root：全局隐藏系统导航栏（需 root / su）。
  • 终端（实验性）：关于页连点版本号打开；修复精简 ROM 缺 PATH/HOME 导致的启动崩溃，错误提示显示异常位置。
  • 系统设置：拨号 #518200# 打开原生系统设置入口。
  • 工程：com.shihab.diplay，versionCode 100；模块 mobile / common / shared；minSdk / targetSdk 19。
